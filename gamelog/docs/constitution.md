# Constitución de GameLog — aprobada el 23 de octubre de 2026

1. **Stack simple:** un solo lenguaje y una sola aplicación; cada dependencia externa debe tener un motivo escrito en el plan.
2. **Spec primero:** todo cambio de comportamiento requiere un requisito aprobado; si código y spec difieren, se corrige el código o se revisa primero la spec.
3. **Reglas separadas:** calcular récords y validar resultados no depende de la interfaz, el reloj ni la lectura o escritura de datos.
4. **Pruebas obligatorias:** cada requisito funcional y caso límite tiene una prueba; la suite completa pasa antes de cada commit de código.
5. **Persistencia controlada:** los resultados se guardan en un único almacén, leído y escrito desde un solo componente; cualquier cambio de formato se documenta antes en la spec.
6. **Idioma:** identificadores, nombres de archivo y comentarios en inglés; mensajes al usuario y documentación en español.
