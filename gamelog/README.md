# GameLog

Proyecto educativo de desarrollo guiado por especificaciones: una página web para registrar resultados personales de videojuegos.

## Idea inicial

- Una sola persona registra sus propios resultados de varios videojuegos.
- Cada juego puede tener varios tipos de récord.
- Hay tipos predefinidos, como puntuación y tiempo, y se pueden crear tipos propios.
- Cada tipo indica si mejora al subir o al bajar su valor.
- Cada resultado se registra por separado y recibe automáticamente la fecha del día en que se guarda.
- Se podrán consultar resultados anteriores y el mejor valor de cada tipo.

Estas decisiones describen la idea inicial. La especificación precisará sus reglas, errores y límites antes de escribir código.
